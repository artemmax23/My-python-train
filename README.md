Задача 1. Группировка по четности

Напиши функцию even_odd(lst: list) -> dict, которая принимает список чисел и возвращает словарь с двумя ключами: 'even' (четные числа) и 'odd' (нечетные числа). Сложность O(n).

───

Задача 2. Поиск дублей

Напиши функцию find_duplicates(lst: list) -> list, которая принимает список элементов и возвращает список элементов, которые встречаются в нем больше одного раза. Порядок не важен, но дубли не должны повторяться в результате.

───

Задача 3. Валидатор скобок

Напиши функцию is_balanced(s: str) -> bool, которая проверяет, правильно ли расставлены скобки в строке. Строка может содержать только скобки ()[]{}, а также буквы и другие символы (их нужно игнорировать).

───

Задача 4. Работа с API и фильтрация по дате

Напиши скрипт, который делает запрос к GitHub API (/repos/python/cpython/commits), получает список коммитов и выводит информацию о коммитах, сделанных за последние 7 дней. Используй библиотеку requests, обработай ошибки сети и пагинацию. Выведи автора, дату и сообщение для каждого коммита.

───

Задача 5. Парсер CSV и конвертер в JSON

У тебя есть файл users.csv с колонками id, name, age, city.

1. Напиши функцию average_age_by_city(csv_filename: str) -> dict, которая читает файл и возвращает средний возраст по городам.
2. Напиши функцию csv_to_json_without_id(csv_filename: str, json_filename: str), которая конвертирует CSV в JSON, исключая поле id.

Задача 6. Кеш с истечением

Напиши класс Cache, который хранит данные в словаре с временем жизни.

· set(key, value, ttl=10) — сохраняет значение на ttl секунд.
· get(key) — возвращает значение, если оно не истекло, иначе None.
· has(key) — возвращает True, если ключ существует и не истек.

───

Задача 7. Слияние отсортированных списков

Напиши функцию merge_sorted_lists(lst1: list, lst2: list) -> list, которая принимает два отсортированных по возрастанию списка и возвращает один отсортированный список, содержащий все элементы из обоих. Не используй sort() или sorted().

───

Задача 8. Two Sum (поиск двух чисел с суммой target)

Напиши функцию two_sum(nums: list, target: int) -> list, которая принимает список чисел (необязательно отсортированный) и целевую сумму. Нужно найти индексы двух чисел, которые в сумме дают target. Используй хэш-таблицу (словарь) для сложности O(n). Решение гарантированно существует и единственное (или верни любую пару).
